# Board — 공유방 · 게시판 · 파일 전송 (GitHub 판)

서버 없이 **GitHub Pages + GitHub 저장소**만으로 돌아갑니다.
로그인은 없습니다. 웹을 연 **그 PC 에 이름이 저장되어**, 다음부터는 주소만 열면 바로 들어갑니다.

## 준비물
GitHub 계정 하나 (방을 만드는 사람만 있으면 됩니다. 참여자는 계정이 필요 없습니다.)

## 설치 (한 번만, 약 10분)

### 1. 저장소 2개 만들기
| 저장소 | 공개 여부 | 쓰임 |
|---|---|---|
| `board` | **Public** | 웹 화면 (GitHub Pages 는 무료 요금제에서 공개 저장소만 됩니다) |
| `board-data` | **Private** | 대화·게시글·파일이 쌓이는 곳 |

둘 다 만들 때 **"Add a README"** 를 체크하세요. (빈 저장소면 시작하지 못합니다.)

### 2. 화면 올리기
`board` 저장소에 `index.html`, `gh-store.js`, `config.json` 세 파일을 올립니다.
`config.json` 안의 저장소 이름을 본인 것으로 고치세요.

    { "repo": "내계정이름/board-data" }

`board` 저장소 → Settings → Pages → Source 를 `main` 브랜치로 지정하면
`https://내계정이름.github.io/board/` 주소가 생깁니다.

### 3. 토큰 만들기 (참여자들이 함께 쓸 열쇠)
GitHub → Settings → Developer settings → **Personal access tokens → Fine-grained tokens** → Generate new token

- Repository access: **Only select repositories** → `board-data` 만 선택
- Permissions → Repository permissions → **Contents: Read and write**
- Expiration: 원하는 기간 (만료되면 새로 만들어 다시 나눠 주면 됩니다)

만들어진 `github_pat_…` 문자열을 복사해 두세요.

### 4. 사람들에게 알려 주기
주소와 토큰을 카톡 등으로 보내 주세요. 받은 사람은 주소를 열고 **이름 + 토큰**만 넣으면 끝입니다.

## 공용 PC 에서 쓸 때 (로그아웃)
이 사이트는 처음 넣은 이름·토큰을 그 PC 에 기억해서, 다음부터는 주소만 열면 들어와집니다.
학교·도서관 같은 공용 PC 에서는 **떠나기 전에 오른쪽 위 `로그아웃`** 을 눌러 주세요.

- 로그아웃하면 이 PC 에 저장된 **이름 · 토큰 · 방 비밀번호**가 지워져, 다음 사람은 토큰 없이 들어올 수 없습니다.
  올린 대화·게시글·파일은 저장소에 그대로 남습니다.
- 로그아웃 창에 나오는 **내 접속 코드**를 보관해 두세요 (카톡 '나에게 보내기' 등).
  다음에 들어올 때 첫 화면의 *전에 쓰던 사람으로 들어오기* 에 코드와 토큰을 넣으면 같은 사람으로 이어집니다.
  코드만으로는 들어올 수 없고 토큰이 함께 있어야 합니다.
- 코드 없이 다시 들어오면 **새 사람**이 됩니다. 참여하던 방에 다시 초대받아야 하고, 전에 올린 파일은 고치거나 지울 수 없습니다.
  특히 **방장**은 코드를 잃으면 그 방에 초대하거나 방을 지울 사람이 없어지므로, 코드를 보관했다고 체크해야 로그아웃됩니다.
- 첫 화면에서 **공용 PC예요** 를 체크하고 들어오면, 로그아웃을 깜빡해도 **브라우저를 닫을 때 저절로** 지워집니다.
  (브라우저의 '이전 탭 복원' 기능을 쓰면 남을 수 있으니, 공용 PC 에서는 그래도 로그아웃을 눌러 주세요.)
- 브라우저가 비밀번호(토큰)를 저장할지 물으면 **저장 안 함**을 누르세요.

## 실시간 편집 (올린 사람이 고치면 다른 사람 화면에 바로 반영)
공유방에 올린 파일과 📁 파일 전송 탭의 파일 중 **500KB 이하 텍스트 파일**(`.py` `.r` `.csv` `.md` `.json` `.txt` 등)이 대상입니다.

- **올린 사람**: 파일 옆 **✎ 실시간 편집** → 그 자리에서 고치면 자동으로 저장됩니다.
  입력을 멈추면 바로, 계속 입력 중이면 3초마다(200KB 넘는 파일은 5초마다) 올라갑니다. `Ctrl+S` 는 바로 저장, `Tab` 은 탭 문자, `Esc` 는 닫기.
- **다른 사람**: **전체 보기** / **👁 보기** → 창을 열어 두면 고치는 내용이 보통 **1~3초 뒤** 나타납니다.
  바뀐 줄은 잠깐 초록색으로, 올린 사람의 커서가 있는 줄은 노란색으로 표시되고 그 위치를 따라갑니다.
- **방에 올린 파일**을 편집하거나 볼 때는 창 오른쪽에 **그 방의 대화**가 나타납니다.
  누가 메시지를 보내면 잠깐 강조되어 나타나고, 편집하던 커서는 그대로입니다. 그 칸에서 바로 답장할 수도 있습니다.
  대화 칸을 숨겨 두면(`✕` 또는 `💬 대화` 버튼) 새 메시지 개수와 함께 오른쪽 위에 잠깐 미리보기가 뜹니다.
  좁은 화면(휴대폰)에서는 접힌 채로 시작하고 `💬 대화` 를 누르면 펼쳐집니다.
  📁 파일 전송 탭의 파일은 딸린 대화가 없어서 이 칸이 없습니다.
- 목록과 대화 화면에는 **수정 중** / **✎ 수정됨 · n분 전** 이 붙고, 내려받기(.txt로 받기 · 다운로드)는 고친 최신본으로 받습니다.
  **원본** 버튼은 처음 올린 그대로를 받습니다.
- **원본으로 되돌리기** 를 누르면 고친 내용을 지우고 처음 올린 파일로 돌아갑니다.
- 고칠 수 있는 사람은 올린 사람뿐입니다. 동시에 여러 사람이 고치는 공동 편집은 아닙니다.
- 방 파일의 고친 내용도 방 비밀번호로 암호화되어 저장됩니다.
- 글자 인코딩이 EUC-KR(CP949) 인 파일도 열리지만, 고친 내용은 UTF-8 로 저장·내려받기 됩니다.

## 어떻게 저장되나요
- `data` 브랜치 → 방 정보·대화·게시글 목록 (JSON)
- `assets` 브랜치 → 첨부 파일 조각
- `live` 브랜치 → 실시간 편집 중인 파일의 고친 내용 (처음 고칠 때 저절로 만들어집니다)
  자주 바뀌는 내용을 `data` 와 떼어 두어, 누가 고치는 동안에도 다른 화면들이 목록을 계속 다시 받지 않습니다.
- Pages 가 쓰는 `main` 브랜치는 건드리지 않아 **사이트가 다시 빌드되지 않습니다.**
- 방 대화와 방 파일은 **브라우저에서 방 비밀번호로 암호화**된 뒤 올라갑니다.
  저장소를 직접 열어도, GitHub 도, 비밀번호 없이는 읽을 수 없습니다.

## 알아둘 점 (GitHub 의 제한)
- **쓰기 횟수**: 토큰 하나당 시간당 약 500회, 분당 80회입니다. 한 사람이 토큰을 공유하면 모두가 이 한도를 나눠 씁니다.
  메시지 1건 = 쓰기 1회라서, 여럿이 폭주하듯 대화하면 잠시 느려질 수 있습니다 (자동으로 기다렸다 보냅니다).
- **새 글 확인**: 4초마다 확인합니다. 메시지는 보통 3~5초 안에 상대 화면에 나타납니다.
  바뀐 게 없을 때의 확인은 사용량에 잡히지 않고, 바뀌었을 때만 **보는 사람 한 명당 읽기 약 2회**(목록 1 + 바뀐 문서 1)가 듭니다.
  읽기 한도는 토큰 하나당 시간당 5,000회입니다.
- **탭을 안 보고 있을 때**는 15초마다 확인하고, 그 사이 쌓인 변경은 한 번에 모아서 받습니다. 탭으로 돌아오면 바로 확인합니다.
- **실시간 편집도 저장 1번 = 쓰기 1회** 입니다. 한 시간 넘게 쉬지 않고 고치면 저장 간격이 3초 → 6초 → 20초로
  저절로 넓어져(편집 창에 표시됩니다) 시간당 쓰기는 약 300회 안쪽에 머뭅니다. 보는 사람 한 명당 저장 1번마다 읽기 1회가 듭니다.
- **`live` 브랜치도 기록이 쌓입니다.** 저장할 때마다 파일 전체가 한 번씩 기록되니, 너무 커지면 `live` 브랜치를 지우세요.
  단, 지우면 **고친 내용이 사라지고 원본만 남으니** 필요한 것은 먼저 내려받아 두세요.
- **접속 중 표시 없음**: 누가 지금 보고 있는지는 표시되지 않습니다 (GitHub 로는 실시간 신호를 보낼 수 없습니다).
- **파일 한 개 20MB**, 저장소 전체는 1GB 안쪽을 권장합니다.
- **지운 파일도 기록에는 남습니다.** 큰 파일을 자주 주고받으면 저장소가 계속 커집니다.
  너무 커지면 `assets` 브랜치를 지우고 새로 만드세요 (예전 첨부는 사라집니다).
- **토큰을 가진 사람은 그 저장소를 모두 읽고 지울 수 있습니다.** 믿는 사람에게만 주세요.
- 토큰은 각자 브라우저에만 저장되고, 저장소에는 올라가지 않습니다. 실수로 올리면 GitHub 가 자동으로 무효화합니다.

## 문제가 생기면
- **"저장소를 찾을 수 없습니다"** → `config.json` 의 이름, 토큰에 그 저장소가 포함됐는지, README 가 있는지 확인
- **"쓰기 권한이 없습니다"** → 토큰 권한을 Contents: **Read and write** 로
- **토큰 만료** → 새로 만들어 각자 ⚙ 에서 교체 (화면이 알아서 다시 물어보기도 합니다)
